## 依赖解析问题及修正

初次 `pnpm add -E` 修改了声明和 specifier，却保留开发版解析。快照测试发现不一致后，使用有明确文档的定向 `pnpm update '@bovinphang/craft-common' --latest --save-exact --ignore-scripts`，只刷新这一公共依赖。重新确认真实安装版本、归档字节及 SRI，再同步快照、重新构建并执行上表测试；早先失败或使用开发版的运行不作为正式版通过证据。

真实 2.0.0 安装后，将后端冲突夹具临时还原为硬编码 2.0.0，前置断言按预期失败；恢复“明确不同版本”的夹具后，生命周期测试通过。没有通过修改 SRI 或屏蔽断言处理解析问题。

临时 scoped registry 只服务实际归档；任务结束已关闭服务、删除任务创建的 `.npmrc`，按原始字节恢复两产品 `pnpm-workspace.yaml`，移除根锁和安装锁中的 loopback URL，并保留真实 SRI。未改全局 registry，未关闭供应链检查。
