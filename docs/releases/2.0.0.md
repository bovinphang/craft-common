## 后续发行与迁移

依赖管理继续使用pnpm12.4.1。公共发行归档先构建，再以pnpm exec npm pack生成并实际解包检查；pnpm12.4.1的pack会排除嵌套pnpm-lock.yaml，不能以该缺锁归档代替。新发行必须使用新版本并保留实际归档/SRI，不自动重复发布当前版本。

共享消费者的公共版本、语言和内容摘要必须一致。先备份编辑，用旧产品CLI退出全部旧公共引用，处理保留文件，再安装匹配产品；不自动升级另一产品，不强制接管未知文件。CLI与同一宿主原生渠道互斥，双产品原生发现去重仍需Runtime专项验证。GUI、签名、真实数据库和生产鉴权不由npm发布结果证明。
